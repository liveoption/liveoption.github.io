LiveOption

Evaluating LLM Agents in Structured Option Trading with Nonlinear Payoffs

02 / Agent design

Analysis and execution

The analysis agent proposes a trade; the execution agent selects contracts and quantities. AVSR summarizes volatility, while QOCR groups contracts by expiry and moneyness.
